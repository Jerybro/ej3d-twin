# R611 約束平衡反應器模型 — 解析化的 Aspen 替代

> 給定進料組成 **A**，封閉式計算反應器出口組成 **B**。
> 全部方程可寫在紙上；參數從 1,004 天實廠數據識別。無 Aspen、無黑箱。

## 1. 機理基礎（Tatoray 甲基轉移反應族）

主反應（甲基在苯環間轉移，**不滅環、不滅甲基**）：

```
R1 歧化    2 TOL  ⇌  BZ + XYL
R2 轉烷    TOL + TMB  ⇌  2 XYL
```

熱力學性質（實測驗證）：甲基轉移近熱中性——三年數據回歸表觀
ΔH₁ = −4.5 kJ/mol、ΔH₂ = −10.7 kJ/mol（≈0）→ **平衡商不隨溫度顯著變化**。

副反應（以進料 TOL mol 的固定比例近似，訓練段中位識別）：
EB/MEB/PB 脫烷基、重芳烴轉烷、環烷裂解。

## 2. 方程組（4 未知 × 4 方程）

以 100 kg 進料為基準，n = kmol，x = 液相 mol 分率。
未知：出口 n_BZ、n_TOL、n_XYL、n_TMB。

```
[環守恆]     n_BZ + n_TOL + n_XYL + n_TMB = R_feed + δR·n_TOL,feed
[甲基守恆]   n_TOL + 2·n_XYL + 3·n_TMB   = M_feed + δM·n_TOL,feed
[歧化平衡商] x_BZ·x_XYL / x_TOL²          = K1
[轉烷平衡商] x_XYL² / (x_TOL·x_TMB)       = K2
```

其中 R_feed = Σ核心四物種進料 mol、M_feed = 甲基加權和；
副產物出口：n_s,out = n_s,in + δ_s·n_TOL,feed（s ∈ {EB, MEB, PB, Indane, C10+, nonARO}）。
牛頓法（數值 Jacobian）60 迭代內收斂，純 numpy 毫秒級。

## 3. 識別參數（訓練段 2020-08 ~ 2023-01，803 天）

| 參數 | 值 | 物理意義 |
|---|---|---|
| K1 | **0.2255** | 歧化平衡商（出口實測三年中位；P10–P90 ±8%） |
| K2 | **2.6659** | 轉烷平衡商 |
| δR | **+0.0518** | 副反應環淨增／mol TOL 進料（EB/MEB 脫乙基流入核心） |
| δM | **+0.0394** | 副反應甲基淨增／mol TOL 進料 |

副產物比例 δ_s：EB +0.0100、MEB −0.0500、PB −0.0107、Indane −0.0053、C10+ −0.0097、nonARO +0.0005。

**模型選擇紀錄（誠實聲明）**：K 的 van't Hoff（1/T）修正與線性活性漂移修正
皆已嘗試，因訓練段溫度與運轉時數強共線，外推段（觸媒末期）表現均**劣於常數 K**。
數據裁決：平衡商為此反應器的**不變量**。

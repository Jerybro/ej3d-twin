# P&ID 拓撲數位化：技術定位與文獻對照

> 對象：`Jerybro/ej3d-twin` @ `feature/pid-labeling`
> 日期：2026-08-10
> 用途：對照前人設定、評估我們的技術差異、標定可延伸方向

---

## 1. 核心對照：Kim et al. 2022（JCDE）

領域內唯一涵蓋完整端到端流程且明確報告拓撲重建成績的論文。

### 它的拓撲重建作法（可直接移植的部分）

| 步驟 | 規則 |
|---|---|
| **文字↔符號綁定** | 完全包覆（重疊 ≥99%）／線穿越文字且方向寬度相符／部分重疊 ≥50% |
| **線↔符號連接** | 符號 bbox 與線端點在容差內即加邊 |
| **符號↔符號連接** | 兩符號 bbox 在容差內即加邊 |
| **線交叉** | **在交點切斷，移除較短的線** |
| **線穿越符號** | 切成兩段，移除被穿越的部分 |
| **斷線重連** | 共線且端點僅單一連接者可重連 |
| **分歧辨識** | 由節點連通度樣態自動判定 tee／cross fitting |

### 它的成績與代價

| 項目 | Precision | Recall |
|---|---|---|
| 符號偵測 | 96.65% | 96.40% |
| 文字辨識 | 90.65% | 92.16% |
| 線偵測 | 95.25% | 87.91% |
| **拓撲重建** | **99.56%** | **96.07%** |

- 訓練資料：75,031 符號 / 10,073 文字 / 90,054 線
- **處理時間：平均 8,488 秒／張（約 2.36 小時）**
- 輸出：DEXPI（Proteus XML）

### 我們與它的關鍵差異

| 面向 | Kim et al. 2022 | 本專案 | 差異性質 |
|---|---|---|---|
| 輸入 | 影像格式 P&ID | **born-digital 向量 PDF** | 不同分支 |
| 符號來源 | CNN 偵測（需 75k 標註） | **向量幾何不變量** | 零訓練資料 |
| 線交叉處理 | 交點切斷、移除較短線 | **跳線弧幾何偵測**（14 個候選） | 我們有向量弧證據，它只能靠長度啟發式 |
| 閥件與線的關係 | 端點吸附 | **橋接缺口**（CAD 截斷線嵌入符號） | ★ 見下節 |
| **處理時間** | **8,488 秒／張** | **34 秒／張** | **約 250 倍** |
| 輸出 | DEXPI | 自訂 JSON（DEXPI 未做） | 我們待補 |

### ★ 一個前人沒明說、我們實測發現的機制

Kim et al. 用「端點吸附」連接線與符號。但在 born-digital CAD 圖上，**閥件不是「在管線上」，而是 CAD 把管線截斷、讓符號嵌進去**——閥的兩側是兩個懸空端，而非一條完整的邊。

我們一開始沿用「找最近管線」的思路，命中率只有 **10%**。改成「找閥件兩側懸空端 → 確認方向接近反向（180°±50°）→ 經閥節點橋接」後，命中率 **98%（83/85）**。

這個差異在點陣圖上不容易觀察到（線被畫成像素，缺口不明顯），是向量路線才看得見的結構事實。

## 2. 我們的獨立驗證設計（前人未見）

Kim et al. 與後續工作皆以單一管線（偵測 → 後處理）產出結果，信心度來自模型分數。我們的設計不同：

### 誤差獨立性作為第一原則

先實作了「同一位置三種尺度裁切各判一次取眾數」的投票法，實測**失敗**——
三個裁切共用同一個中心，中心錯了三票一起錯（`R101` 三塊全讀成 `FR 65101`）。
**投票只在誤差獨立時有意義。**

改為真正獨立的證據組合：

| 方法 | 抓什麼 | 與 OCR 的獨立性 |
|---|---|---|
| 全頁分塊 OCR | 位號文字（高召回） | 基準 |
| **氣泡錨定 OCR** | 只在幾何找到的元件內讀字 | 輸入框定不同 |
| **氣泡幾何** | 130 個儀錶氣泡 | **完全獨立**（不經 OCR） |
| **閥件幾何** | 85 顆閥（等長線段共用中點） | **完全獨立** |
| ISA 5.1 規則 | 字母碼語意 | 確定性 |
| 編號族群一致性 | 6xx vs 1xx 離群 | 確定性 |
| VLM | 補讀、安裝別判定 | **完全獨立**（不同模型） |

信心度定義為「**被幾種獨立方法找到**」，而非任一模型的自評分數。

實測意義：OCR 對 `R101` 的信心是 **1.0**，但圖上根本沒有這個位號——
單一模型的信心分數無法偵測這類錯誤，跨方法一致性可以。

### ISA 5.1 文法作為確定性解碼層

前人多把 ISA 位號當作「待辨識的文字」。我們把它當作**規範化的先驗知識**：
讀字母交給 OCR/VLM，解語意交給規則表。

實測 VLM 會把 `PDT` 說成「密度指示」（正解壓差傳送器）、`TT` 說成「雙色溫度計」（正解溫度傳送器）。規則表解碼後錯誤率歸零。
控制迴路分群（17 組、4 組結構完整）亦完全由 ISA 文法推得，**零視覺判讀**。

## 3. 對照 Stürmer et al. 2024（PID2Graph）

- 把 P&ID 視為 image-to-graph，Relation transformer 同時產生 bbox 與關係邊
- 邊偵測較模組化 baseline 提升 >25 個百分點
- **需要 60 張真實標註 P&ID**

**我們的取用方式**：不改用 Transformer（向量法在 born-digital 上更好），但
**資料模型 schema 對齊 PID2Graph 的圖標註定義**——未來要比較、發表、接 DEXPI 都省事。

---

## 4. 對照 SynthPID（CVPR 2026 Workshop AI4RWC）

- 指出 Paliwal 等人 Dataset-P&ID 的「32 種模板隨機散佈」合成法，
  在節點度分布、元件聚集、流向性上都不像真實廠 → 純合成訓練在真圖上顯著劣化
- 改用**保留拓撲**的合成資料後有約 30 個百分點的落差擺盪
- 誠實限制：12 個底層拓撲不論擾動幾次都不會產生新的接點構型

**對我們的意義**：向量路線不需要合成資料。此篇僅在未來處理掃描圖時適用，
且屆時應先累積 **20–30 張不同廠型的真實拓撲當種子**，而非隨機組合模板。

已實測佐證掃描圖的難處：中油大林那批影像上，
向量方法（閥件、氣泡、線段）**全數歸零**，只剩 OCR 單腳走路。

## 5. 評估方法：我們該怎麼報成績

前人設定值得沿用的部分：

1. **分項報告** precision / recall，不要只給一個總分
   （符號／文字／線／拓撲各自報，讀者才知道瓶頸在哪）
2. **拓撲另計**——拓撲對錯與符號對錯是兩件事
3. **報處理時間**（前人 8,488 秒／張，這是我們最大的量化優勢）

我們應補上而前人少做的：

4. **報「誤判」而非只報命中**——假位號（`R101`/`T108`/`D181`/`E653`）
   是實務上最貴的錯誤，只報 recall 會掩蓋它
5. **報方法獨立性的貢獻**——單一方法 vs 多方法交叉的差異
   （實測：氣泡錨定單獨使用時四個假位號全數消失，但召回從 92 降到 84）
6. **報跨圖完整性**——單張成績再高，圖組缺一張整廠拓撲就是斷的
   （實測台化 C12070-1 有 7 個接續標記指向不存在的圖）

### 目前可報的數字（C12070-1，A3 向量 PDF）

| 項目 | 數值 | 備註 |
|---|---|---|
| 閥件偵測 | 85 顆，疊圖驗證零誤判 | 純幾何 |
| 儀錶氣泡 | 130 個 | 純幾何 |
| 儀錶位號 | 95（雙法確認 84 / 單法 11） | 兩法交叉 |
| 閥件管線歸屬 | **98%（83/85）** | 前人未單獨報此項 |
| 控制迴路分群 | 17 組，4 組結構完整 | ISA 文法，零視覺 |
| 全圖處理時間 | **34 秒** | 對照前人 8,488 秒 |
| 假位號偵測 | 4 個中抓到 3 個 | 族群一致性＋氣泡幾何 |

⚠️ 尚未有標註 ground truth，上述為實測數量與人工抽查，**不是嚴謹的
precision/recall**。要對外發表必須先建立標註集。

## 7. 可延伸的新方向（文獻中尚未看到）

1. **向量原生的跳線判定**：前人在點陣圖上只能用「移除較短線」的啟發式；
   我們有跳線弧的幾何證據。這是 born-digital 路線的獨有紅利，值得單獨驗證與發表。

2. **符號嵌入式截斷的橋接**：閥件橋接（10%→98%）這個機制在文獻中未見明確描述，
   因為點陣路線觀察不到 CAD 的截斷結構。

3. **跨方法誤差獨立性作為信心度**：文獻普遍用模型信心分數；
   「被幾種獨立方法找到」是可驗證且抗幻覺的替代定義。

4. **PFD／P&ID 圖種自動判定與規範切換**：文獻聚焦 P&ID 單一圖種；
   實務上一疊圖裡混著 PFD、P&ID、清單表，判錯圖種等於整套規則失效。

5. **設備清單表作為 L0 資產登錄**：PFD 上的設備清單表是結構化資產資料，
   文獻多視為雜訊排除；正確作法是以另一套規則解析並與圖面項次號 join。
